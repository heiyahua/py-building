# PyInstaller 图形化封包工具

`pybuild_tool.py` 是一个基于 PyInstaller 的中文图形化打包工具，面向 Windows 桌面程序，把常用的打包命令封装成可视化操作。

## 环境要求

- Windows 10 及以上，Python 3.10+
- 无需手动安装 PyInstaller、Pillow、UPX，工具会自动检测并下载

## 启动

```bash
python pybuild_tool.py
```

## 功能一览

| 功能 | 说明 |
|---|---|
| 虚拟环境 | 自动创建或复用虚拟环境，隔离打包依赖 |
| 依赖检查 | 解析入口脚本的 import，缺失的第三方库自动 pip 安装 |
| 打包模式 | 单文件 / 目录，可选隐藏控制台窗口 |
| UPX 压缩 | 默认开启；PATH 中没有时自动下载并复用 |
| 程序图标 | 支持预览；PNG/JPG/BMP 自动转为 16~256 多尺寸 ICO |
| 附加数据 | 文件或整个文件夹打包进程序资源目录 |
| 高级参数 | 直接追加任意 PyInstaller 参数，如 `--hidden-import=xxx` |
| 版本信息 | 可写入版本号、公司名、产品名、版权、文件描述 |
| 配置记忆 | 自动保存上次配置到 `pybuild_tool_config.json` |

## 使用步骤

1. 选择入口 `.py` 脚本，填写程序名称与输出目录
2. 确认虚拟环境路径（默认在脚本目录下 `.build_venv`）
3. 选择打包模式（单文件 / 目录），按需关闭控制台窗口
4. 选择程序图标：`.ico` 直接使用，图片会自动转换
5. 需要随程序携带的资源，添加到"附加数据"
6. 需要时填写附加参数、版本信息和版权
7. 点击"开始打包"，在日志窗口查看全过程，完成后可自动打开输出目录

## 图标说明

- 选择 PNG/JPG/BMP 后立即自动转换，生成含 16/20/24/32/40/48/64/96/128/256 的 `.ico`，转换结果保存在工具目录 `converted_icons/`
- 勾选"图标同时以 app_icon.ico 打包进资源目录"后，程序内可用 `iconbitmap` 正常加载窗口图标
- 缺少 16/32/48/64 等常用尺寸时日志会给出提示

## UPX 说明

- 默认启用；留空目录时先查 PATH，找不到自动下载 UPX 4.2.4 到工具目录 `upx/` 供后续复用
- 下载失败会自动降级为不压缩继续打包，不中断流程

## 配置说明

- 所有选项（含图标、附加数据、版本信息）自动保存，下次启动恢复
- 首次启动且无配置文件时，各字段为空白状态，不做任何预填

## 日志说明

日志窗口统一按 UTF-8 输出，并兼容 GBK 子进程输出，中文路径与提示不会乱码。
